# Personal Portfolio Website

A responsive personal portfolio website developed to showcase my technical skills, academic background, projects, and contact information as a Computer Science Engineering (CSE) student.

## Features

- **About Me:** Introduction and career objectives.
- **Skills:** Displays technical skills and programming knowledge.
- **Projects:** Showcases academic and personal projects with descriptions.
- **Resume:** Provides access to my resume.
- **Contact Section:** Displays contact information for professional communication.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Interactive UI:** Uses JavaScript to enhance the user experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Getting Started

### Prerequisites

You need a web browser and a code editor such as Visual Studio Code.

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Project Folder

```bash
cd Portfolio
```

### Step 3: Open the Website

Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the website.
